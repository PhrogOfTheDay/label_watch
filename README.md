This project is created to allow users to have a simple CLI based application which allows them to track and be notified of changes related to pharmaceutical items that they have an interest in. Personally, this project was undertaken to help me understand how to work with data that comes from live APIs, how to clean and work with messy data on the go instead of relying on clean, preprocessed data stored in files
